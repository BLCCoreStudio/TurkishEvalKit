# Code of Conduct

TurkishEvalKit is a professional, evidence-driven open-source project.

## Expected behavior

- Discuss code, datasets, metrics, and evaluation methodology respectfully and precisely.
- Separate reproducible findings from preferences or speculation.
- Critique implementations and research decisions rather than people.
- Disclose important assumptions, conflicts, and limitations when they affect a contribution.
- Respect maintainer decisions on project scope, compatibility, methodology, and release policy.

## Unacceptable behavior

Harassment, threats, discriminatory attacks, personal insults, deliberate disruption, spam, falsified evidence, or publishing another person's private information are not acceptable.

## Enforcement

The maintainer may edit, hide, lock, or remove content and may restrict participation when necessary. Severe or repeated violations may result in a permanent ban from project spaces.

## Reporting

Use an appropriate private GitHub channel for conduct concerns that should not be discussed publicly. Security vulnerabilities must follow `SECURITY.md`.
