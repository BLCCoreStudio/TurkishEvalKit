# TurkishQualityKit rename staging

This branch stages the product rename from **TurkishEvalKit** to **TurkishQualityKit**.

- Product: `TurkishQualityKit`
- Python distribution/package: `turkishqualitykit`
- CLI: `turkishquality` and `turkishquality-queue`
- Internal prefix where applicable: `TURKISHQUALITY` / `TURKISHQUALITYKIT`

The public repository slug intentionally remains `BLCCoreStudio/TurkishEvalKit` for now because the submitted job application references that URL. The repository itself must not be renamed until the final cutover.
