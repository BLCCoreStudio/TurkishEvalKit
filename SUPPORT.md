# Support

TurkishEvalKit is maintained as a research-oriented open-source evaluation toolkit. Reports should contain enough evidence to distinguish implementation defects from disagreements about evaluation methodology.

## Bugs

Use the bug report template. Include the package version or commit, Python version, operating system, a minimal reproducible example, relevant input data where it can be shared, expected output, actual output, and the complete traceback or logs.

## Evaluation or methodology concerns

Describe the metric, dataset, rubric, evaluator, or pipeline involved and provide a minimal example that demonstrates the concern. Methodology changes require stronger evidence than ordinary implementation fixes because they can change historical comparability.

## Feature requests

Describe the evaluation problem first, then the proposed capability. Requests that duplicate existing primitives may be closed in favor of composition or documentation improvements.

## Security

Do not publish suspected vulnerabilities in public issues. Follow `SECURITY.md`.

## Maintenance priority

Priority is given to correctness, reproducibility, security, regressions, data integrity, compatibility, and changes that improve the toolkit for a broad set of evaluation workflows.
